# Indian-Lok-Sabha-2024-Dashboard-Tableau
🇮🇳 Indian Lok Sabha 2024 Election Dashboard – Tableau 📊

A comprehensive and interactive Tableau dashboard built to analyze the 2024 Indian Lok Sabha Election 🗳️. The project transforms election data into meaningful visual insights through party-wise and state-wise seat analysis, vote share, winning candidates, constituency performance, and election trends 📈.

🔍 Key Highlights:

🏛️ Party-wise seat distribution

🗺️ State-wise election performance

📊 Vote share analysis

🏆 Winning candidate insights

📈 Interactive charts and KPIs

🎛️ Dynamic filters and dashboard interactions

💡 Data-driven election insights

🛠️ Skills Demonstrated: Tableau, Data Analysis, Data Visualization, Dashboard Design, Data Cleaning, and Data Storytelling.

🎯 This project showcases the ability to convert complex datasets into clear, interactive, and decision-oriented visualizations.
